# Saiesha's 1st Birthday Invitation

Vite + GSAP (ScrollTrigger) + Lenis + canvas-confetti.

## Run
    npm install
    npm run dev       # local preview
    npm run build     # outputs ./dist, upload it to any static host

## Customize
- Time, venue, address, dress code, countdown date, optional WhatsApp number: edit `CONFIG` at the top of `src/main.js`.
- Posters: replace `public/poster1.jpg` and `public/poster2.jpg` (or edit the `src` in `index.html`).
- Colors and fonts: `src/style.css` (CSS variables at the top, with dark-mode values).
